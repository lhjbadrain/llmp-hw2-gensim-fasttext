# 复现记录与公开版说明

完整步骤见 [README](../README.md)。仓库只包含元数据；原始数据由复现者单独提供。

原本地工程先在新的空输出目录完整重建一次；随后公开版将标注正文移除，加入按原文哈希恢复正文的读取函数，并再次在独立目录完整运行。两个任务的划分、逐篇预测与指标均与原记录一致。

- [原本地复现核对](../records/reproduction_check.json)
- [公开代码完整复现核对](../records/public_reproduction_check.json)

没有将重新运行的耗时替换原始实测耗时。记录中的历史模型哈希与输入哈希属于原本地实验，文件删全文、路径相对化、文本LF换行等公开处理后会有新的文件哈希；发布文件清单另行记录。

数据选择及AI辅助标注仍限制结论，复现一致不等于证明模型有普遍优越性或标签没有争议。
